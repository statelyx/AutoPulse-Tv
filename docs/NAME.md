# Molaqo

Ürün adı: Molaqo. Okunuş önerisi: “molako”. Kısa, mola çağrışımlı bir kişisel video uygulaması adı.

6 Kasım 2026 tarihindeki sınırlı web aramasında aynı isimle bir video uygulaması doğrulanmadı. Bu bir marka araştırması, tescil onayı veya App Store ad rezervasyonu değildir. Mağaza kaydı açılırken kullanılabilirlik ayrıca kontrol edilmeli.

Teknik adlar:

- Xcode proje / scheme / Swift modülü: Molaqo
- Önerilen bundle ID: com.statelyxx.molaqo
- Önerilen GitHub depo adı: molaqo-ios
- Kaynak proje: kullanıcının Masaüstü/Molaqo klasörü

GitHub namespace'i kullanıcı talebiyle statelyxx olarak hedefleniyor; önceki ekranda kullanıcı adı statelyx, görünen ad statelyxx idi. Hesap erişimi engellendiği için depo sahibi doğrulanmış değildir. Bundle ID henüz Apple hesabında kaydedilmedi.
